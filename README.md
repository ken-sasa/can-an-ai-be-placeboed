# Can an AI Be Placeboed, Dressed, Stamped, and Contaminated?

Reproducibility materials for:

**Can an AI Be Placeboed, Dressed, Stamped, and Contaminated? Five Prospective Tests of Human-Like Context Effects in a Large Language Model**

Author: **Kento Sasano** (Okayama University)

Canonical public repository: **https://github.com/ken-sasa/can-an-ai-be-placeboed**

Release: **v1.0.0 (arXiv v1 reproducibility package)**

## Public GitHub contents

- manuscript source and human-readable research documentation;
- analysis code and locked manuscript-facing numerical summaries;
- citation, licensing, and Zenodo metadata.

The **exact complete reproducibility package**—including protocols, generated task banks, manifests, frozen analysis code, condition-level outputs, result summaries, run-freeze records, six final experiment artifacts covering 956 paid API calls, figures, tables, and rebuild scripts—is frozen in the Zenodo v1.0.0 archive.

## Reproducibility boundary

This public repository is a curated research compendium. It intentionally excludes private repository history, credentials, GitHub Actions secrets, and operational paid-run gates. The Zenodo package contains the complete research artifacts required to rebuild the manuscript-facing synthesis without additional API calls.

## Model scope

All six core experiments used the API model identifier `gpt-5.6-terra` with reasoning effort `medium`. The archive records the returned model identifiers, task banks, manifests, result summaries, and run-freeze metadata available at execution time. It does not imply permanent reproducibility of a proprietary hosted model.
